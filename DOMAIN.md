# Подключение своего домена

Сейчас сайт работает здесь:

https://huanmrvz.github.io/galina_site/

Хостинг остаётся на GitHub Pages. Домен только «приклеивается» сверху.

## Что нужно от вас

1. Купить домен (например `galinaavedova.ru`).
2. Написать сюда точное имя домена.
3. Иметь доступ к DNS у регистратора (Reg.ru, Timeweb, Beget, Cloudflare и т.п.).

После этого в репозитории появится файл `CNAME`, а в GitHub Pages будет указан custom domain.

## Шаги (когда домен уже есть)

### 1. Файл в репозитории

В корне должен лежать файл `CNAME` с одной строкой — вашим доменом, без `https://`:

```
galinaavedova.ru
```

### 2. DNS у регистратора

Рекомендуемый вариант — и apex, и `www`.

**Apex-домен (`galinaavedova.ru`):**

| Тип | Имя / Host | Значение              |
|-----|------------|-----------------------|
| A   | `@`        | `185.199.108.153`     |
| A   | `@`        | `185.199.109.153`     |
| A   | `@`        | `185.199.110.153`     |
| A   | `@`        | `185.199.111.153`     |

**Поддомен `www`:**

| Тип   | Имя / Host | Значение              |
|-------|------------|-----------------------|
| CNAME | `www`      | `huanmrvz.github.io`  |

> Важно: в CNAME указывайте именно `huanmrvz.github.io`, не `huanmrvz.github.io/galina_site`.

Если регистратор поддерживает IPv6, можно добавить AAAA:

| Тип  | Имя | Значение             |
|------|-----|----------------------|
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |

Старые A/CNAME-записи на Тильду или другой хостинг лучше удалить, чтобы не конфликтовали.

### 3. Настройка в GitHub

1. Откройте: https://github.com/huanmrvz/galina_site/settings/pages
2. В поле **Custom domain** введите домен → **Save**
3. Дождитесь галочки DNS check (обычно от нескольких минут до 24 часов)
4. Включите **Enforce HTTPS**

Либо это можно сделать через меня в чате — после того как назовёте домен.

## Проверка

Когда DNS подтянется:

- http://ваш-домен.ru  
- https://ваш-домен.ru  
- https://www.ваш-домен.ru (если настроили www)

Проверить DNS можно тут: https://dnschecker.org/

## Частые проблемы

- **DNS check не проходит** — подождите, кэш DNS обновляется не мгновенно
- **HTTPS не включается** — сначала должен пройти DNS check, потом GitHub выпускает сертификат
- **Открывается старый сайт / Тильда** — очистите старые DNS-записи у регистратора
- **404 на кастомном домене** — убедитесь, что Pages source = branch `main` / `/ (root)`

## После подключения

Сайт по-прежнему обновляется так:

```bash
git add .
git commit -m "Update site"
git push
```

Через 1–2 минуты изменения появятся и на своём домене.
