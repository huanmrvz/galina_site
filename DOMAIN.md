## DNS у регистратора

Пропишите эти записи (старые A/CNAME на другой хостинг удалите):

**Для `avedovapsy.ru` (основной домен):**

| Тип | Имя / Host | Значение          |
|-----|------------|-------------------|
| A   | `@`        | `185.199.108.153` |
| A   | `@`        | `185.199.109.153` |
| A   | `@`        | `185.199.110.153` |
| A   | `@`        | `185.199.111.153` |

**Для `www.avedovapsy.ru` (рекомендуется):**

| Тип   | Имя / Host | Значение             |
|-------|------------|----------------------|
| CNAME | `www`      | `huanmrvz.github.io` |

Опционально IPv6 (AAAA) для `@`:

| Тип  | Имя | Значение              |
|------|-----|-----------------------|
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |

> В CNAME указывайте именно `huanmrvz.github.io`, без `/galina_site`.

## Проверка

1. DNS: https://dnschecker.org/#A/avedovapsy.ru
2. Сайт: https://avedovapsy.ru/
3. В GitHub: Settings → Pages → должна быть галочка DNS check
4. Включите **Enforce HTTPS** (после проверки DNS, обычно через несколько минут–часов)

DNS может обновляться от нескольких минут до 24 часов.
